# Python
## Introduction
* Python is a high-level, general-purpose programming language created by Guido van Rossum, first released in 1991. 
* It emphasizes code readability and simplicity, using clean, English-like syntax that lets developers express concepts in fewer lines than languages like C++ or Java. 
* It's widely used in web development, data science, AI/ML, automation, scripting, and scientific computing.

## Salient Features
1. Simple and Readable Syntax
   * Python code reads almost like plain English. It uses indentation (not braces) to define code blocks, which enforces clean, consistent formatting.
2. Interpreted Language
   * Code is executed line-by-line by an interpreter, so there's no separate compilation step — great for quick testing and debugging.
3. Dynamically Typed
   * You don't need to declare variable types explicitly; Python figures them out at runtime.
4. Interpreted & Portable
   * Python runs on Windows, macOS, Linux, and more without modification — "write once, run anywhere."
5. Extensive Standard Library
   * Python ships with a huge built-in library ("batteries included") covering file I/O, math, networking, JSON, regex, and more.
6. Vast Ecosystem of Third-Party Packages
   * Via pip and PyPI, developers get access to hundreds of thousands of packages — NumPy, Pandas, Django, Flask, TensorFlow, PyTorch, etc.
7. Multi-Paradigm
   * Supports procedural, object-oriented, and functional programming styles, giving developers flexibility.
8. High-Level Language
   * Abstracts away low-level details like memory management, letting developers focus on logic rather than hardware specifics.
9. Free and Open Source
   * Python is free to use, distribute, and modify, with a large, active community driving its development.
10. Extensible and Embeddable
    * Python can be extended with C/C++ code for performance-critical tasks, and can also be embedded into other applications as a scripting layer.
11. Automatic Memory Management
    * Uses garbage collection to automatically manage memory allocation and deallocation.
